# Music Playlist

A React-based music playlist application built using React, Vite and React Router.

## Features
- Browse songs
- Filter songs by genre
- View song details
- Add and remove songs from your playlist
- View total playlist duration
- Trending song indicator

## Technologies Used
- React
- Vite
- React Router
- JavaScript
- CSS

## Run Locally

```bash
npm install
npm run dev
```
